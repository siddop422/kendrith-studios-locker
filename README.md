# Kendrith Studios Locker — Chromaforge

A beautiful local vault for every file your studio makes, with RGB lighting, glassmorphism, and vault optimization.

## Features
- Drag & drop any files/folders (stored in IndexedDB on device)
- Categories, search, tags, notes, starring
- RGB lighting modes (Spectrum, Aurora, Cyber, Plasma, etc.)
- Performance mode, glass blur controls
- Vault Optimizer & duplicate scanner
- Batch rename, ZIP download, custom order
- Fully client-side — nothing leaves your browser

## Deploy
